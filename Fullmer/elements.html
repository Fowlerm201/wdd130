Common HTML Elements

HTML contains many elements, but you only need a few to begin building a simple webpage. Headings, paragraphs, links, and images are some of the most common. Headings help organize a page into sections. HTML has heading levels from h1 to h6. An h1 is often used for the main page heading, while an h2 can introduce a section underneath it. Paragraphs are created with the p element. They can be used for explanations, introductions, and other blocks of text.

Links are created with the a element. The href attribute tells the browser where the link should go. A link can lead to another page on your website or to a different website. Images are added with the img element. Its src attribute tells the browser where to find the image. Its alt attribute provides a text description for people using screen readers and for situations when the image cannot be displayed.
