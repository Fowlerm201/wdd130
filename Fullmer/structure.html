The Structure of an HTML Page

Every HTML webpage follows a basic structure. This structure helps the browser understand where the page begins and what information it contains. At the top of a document, a doctype declaration tells the browser that the document uses modern HTML. The rest of the page is placed inside the html element. Within it are two main parts: the head and the body. The head contains information about the webpage, such as its title. The title usually appears on the browser tab. The body contains the content visitors see on the page, including headings, paragraphs, links, and images.

Most HTML elements use an opening tag and a closing tag. The content goes between those tags. Some elements, such as images, do not need a closing tag. Indenting nested elements can make your code easier to read and help you notice missing or misplaced tags. As you build more pages, keeping your code organized can also make it easier to update.
