Ice Projects

Prophet Card

This was the first project. It's a prophets card of Dallin H. Oaks. The card has simple facts about Dallin H. Oaks and a quote. The challenge was to create a website that matched a given wireframe. I learned how to apply what I've learned into an ice challenge for the first time.

Favorite Devo

This page is favorite devotionals. It has a table with the speaker, title, location, and year of the devotional. It also has a form to add another favorite devotional. I learned how to add tables and forms.

Holiday Page

This is a halloween themed website. I got to add my own style to the website. The ice challenge was to add your ideas for a website with only some elements given. I learned how to create the css for a website and there was no wireframe.

Css Positioning

The CSS positioning shows the results of using grids to change shapes to match an image given. This helped me learn how grid works and how to rearrange elements on the grid.

Flags

This page shows multiple flags. The ice challenge was to create flags for Denmark, Finland, Benin, Italy, and C.A.R.. I learned how to change the css to match the flag given. I had to think how each change would affect the output.

Image Gallery

This page is an image gallery of Christ. It shows 12 different pictures. The ice challenge was to optimize the image loading by shrinking the image size. When completed the images load quickly when the website is loaded. I learned the recommended sizes and type of image to use for a website.

Sign Up

This page shows a newsletter to sign up for daily scriptures feed. It has a form to fill out and a picture of Christ at the top and multiple scriptures at the bottom of the page. For this ice challenge the basic html was given and you added what you needed for the css. The main part was changing the css to match a given newsletter. I learned how to apply all the ice challenges in one website.
